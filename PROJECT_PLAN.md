# MaintIQ — PROJECT_PLAN.md (Source of Truth)

**Goal:** Complete Industrial Predictive Maintenance & Decision Intelligence Platform with real data lineage.

**Architecture:** React → FastAPI REST → Service layer → SQLAlchemy repos → PostgreSQL. Pipeline: Raw → Validate → DQ → Transform → Warehouse → Analytics/ML → API → React.

**Tech Stack:** React 19, TypeScript, Vite 8, Tailwind 4, React Router 7, Recharts 3, Lucide. Backend: Python, FastAPI, Pydantic, SQLAlchemy, Alembic, PostgreSQL. Data: Pandas, NumPy, scikit-learn, XGBoost if justified. Tests: Vitest+RTL (5/5), Pytest+TestClient (11/11).

## Global Constraints
- No mock data in production paths; demo isolated in `data/demo/` or `backend/seed/`
- No tokens in localStorage/sessionStorage; server sessions + HttpOnly SameSite=Lax cookies
- No frontend-only authz; enforce RBAC server-side
- Every KPI traceable: dataset → ingestion → DQ → DB → analytics → API → UI
- Historical wording only: "Historical dataset / Analytical snapshot / Last ingestion" — never "Live"
- No RUL unless dataset supports it
- Modular monolith; no microservices/K8s/Kafka/Redis/GraphQL unless justified
